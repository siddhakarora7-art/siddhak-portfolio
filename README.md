# Siddhak Arora — Personal Portfolio

A responsive single-page portfolio built with HTML, CSS and JavaScript.

## Files

- `index.html` — page content and structure
- `style.css` — visual design, layout and responsive styling
- `script.js` — mobile navigation and dynamic footer year

## Run locally

1. Download or clone this repository.
2. Keep all three files in the same folder.
3. Open `index.html` in a browser, or use VS Code Live Server.

## Publish with GitHub Pages

1. Push these files to the root of the `main` branch.
2. Open the repository on GitHub.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to finish deploying. The public URL will usually be:
   `https://siddhakarora7-art.github.io/siddhak-portfolio/`
